# Семантична сторінка з навігацією та картками послуг

## Мета проєкту
Навчальний проєкт для відпрацювання базової семантичної розмітки HTML5, методології іменування класів BEM, а також розмежування задач між Flexbox (для лінійної навігації) та CSS Grid (для двовимірної сітки карток) із забезпеченням стійкості верстки до довгих текстових заголовків.

## Використані технології
* **Семантика HTML5:** використання тегів `header`, `nav`, `main`, `section`, `article`, `footer`.
* **BEM:** компонентна архітектура класів (`блок`, `блок__елемент`, `блок--модифікатор`) без стилізації за тегами.
* **Flexbox:** побудова горизонтального навігаційного меню та внутрішнього вирівнювання елементів карток із відступами через `gap`.
* **CSS Grid:** розміщення карток у рівномірній сітці (`repeat(3, 1fr)`) із фіксованими проміжками через `gap`.
* **Захист від переповнення:** застосування `min-width: 0` для flex-контейнерів та `overflow-wrap: anywhere` для коректного переносу довгих слів.

## Результат перевірки
Розкладку перевірено в браузері (DevTools). Навігаційне меню побудовано на Flexbox із вирівнюванням через `gap`, картки розташовані у простій Grid-сітці, стилі компонентів відповідають методології BEM, горизонтальний скрол на сторінці відсутній навіть при тестуванні у вузькому viewport.
Use code with caution.
